# Bill of Materials

The specific hardware we used developing and testing Brume — the exact
parts, not a requirements list. Brume targets stock Pi hardware; see
[HARDWARE.md](HARDWARE.md) for what's actually needed and what's
interchangeable. These are plain product links, no affiliate.

## Compute

- [Waveshare Compute Module 5 (CM5)](https://www.amazon.com/dp/B0DQZQQJN2) — WiFi SKU, 8 GB RAM, 32 GB eMMC
- [Waveshare CM5 IO Board (PoE)](https://www.amazon.com/dp/B0DPH2NRKC) — the USB_OTG jumper is what enables Meridian

## Display (we tested two)

- [MAGEX 10.1" IPS touchscreen, 1920×1200](https://www.amazon.com/dp/B0FN81KTHW) — current reference panel
- [WIMAXIT 10.1" touchscreen, 1024×600 (Mini HDMI)](https://www.amazon.com/dp/B09QPWRCB1) — used on the Pi 5 prototype (listing currently unavailable)

## MIDI controllers

Both are first-class control surfaces — auto-detected on connect, no setup.

- [Korg nanoKONTROL2](https://www.amazon.com/dp/B004M8UZS8)
- [Novation Launch Control XL 3](https://www.amazon.com/dp/B0F43TDF84)
